# Dokumentprofile und Rechercheansätze

Diese Startpunkte sind eigene Arbeitsraster, keine zitierten Normen und keine abschliessenden Best Practices. Für jeden Auftrag passende aktuelle Primärquellen recherchieren. Bei Mischformen relevante Module kombinieren.

| Dokumenttyp | Typische Prüffragen | Geeignete Rechercheziele |
|---|---|---|
| Angebot, Offerte, Ausschreibungsantwort | Bedarf, Abdeckung, Lieferobjekte, Preise, Leistungsgrenzen, Team, Vertragskonsistenz, Wettbewerb | Kundenunterlagen, zuständige Vergabestellen, anwendbare Beschaffungsleitfäden |
| Strategie, Konzept, Business Case | Problem, Ausgangsdaten, Alternativen, Ziele, Wirkungskette, Ressourcen, Umsetzung, Messung | Zuständige Fachstellen, anerkannte Fachverbände, offizielle Bewertungs- und Planungsleitfäden |
| Bericht, Analyse, Evaluation | Fragestellung, Datenbasis, Methode, Ergebnisse, Grenzen, Folgerungen | Fachlich zuständige Statistikstellen, Evaluationsgesellschaften, offizielle Methodenhandbücher |
| Studie, wissenschaftlicher Text | Forschungsfrage, Studiendesign, Stichprobe, Auswertung, Reproduzierbarkeit, Ethik, Limitationen | Fachspezifische Reporting-Guidelines, Originalforschung, Publikationsvorgaben |
| Vertrag, Reglement, Richtlinie | Begriffe, Geltung, Rollen, Rechte/Pflichten, Fristen, Rangfolge, Widersprüche, Verfahren | Offizielle Rechtsquellen, zuständige Aufsicht, anwendbare amtliche Leitlinien; keine juristische Freigabe |
| Protokoll, Agenda, Beschlussvorlage | Sachstand, Optionen, Beschlüsse versus Diskussion, Zuständigkeiten, Termine, offene Punkte | Organisationsregeln, einschlägige Geschäftsordnungen und offizielle Verfahrensleitfäden |
| Medienmitteilung, Artikel, Social Post, Rede | Nachrichtenwert, Tatsachen/Meinung, Belege, Kontext, Zielgruppe, Ton, Handlungsaufforderung | Redaktionelle Standards, offizielle Kommunikationsleitfäden, zuständige Fachquellen |
| Lehrmaterial, Lernplan, Prüfung | Zielgruppe, Lernziele, fachliche Richtigkeit, Aufgabenpassung, Transfer, Bewertung, Zugänglichkeit | Lehrplan, Bildungsträger, einschlägige didaktische und Prüfungsleitlinien |
| Präsentation, Infografik | Kernaussage, Dramaturgie, Beleglage, Visualisierung, Lesbarkeit | Offizielle Gestaltungs-, Datenvisualisierungs- und Barrierefreiheitsleitlinien |
| Tabelle, Budget, Finanzmodell | Formeln, Annahmen, Szenarien, Rechenbasis, Abstimmung, Datenstand | Anwendbare Rechnungslegungsregeln, offizielle Daten, fachliche Modellierungsleitlinien |
| Handbuch, technische Spezifikation, Prozess | Nutzeraufgabe, Voraussetzungen, Schritte, Ausnahmen, Schnittstellen, Prüfbarkeit, Pflege | Offizielle Produktdokumentation, Standardgeber, fachliche Prozess- und Qualitätsleitfäden |
| Bewerbung, Lebenslauf, Schreiben | Adressatenpassung, Chronologie, Nachweisbarkeit, Klarheit, erwartete Antwort | Anforderung der empfangenden Stelle, einschlägige öffentliche Berufs- und Kommunikationsleitfäden |
| Kreativer oder persönlicher Text | Intention, Perspektive, innere Stimmigkeit, Wirkung, sensible Tatsachenbezüge | Gattungsspezifische seriöse Fachquellen, sofern nützlich; keine Recherche zu privaten Inhalten |
| Sonstiges | Zweck, Zielgruppe und belastbare Bewertungskriterien zuerst rekonstruieren | Zuständige Fachinstitutionen; fehlenden etablierten Standard offenlegen |

Bei Angebotsreviews zusätzlich die Angebotsreferenz nutzen. Bei allen anderen Typen keine Zuschlagsrisiken, Wettbewerber oder Angebotsreife erzwingen.
